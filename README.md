# onk3sh.github.io

Personal portfolio site built with Astro.

## Tech Stack

- **Framework**: [Astro](https://astro.build/)
- **Styling**: Vanilla CSS
- **Content**: TypeScript-driven project data
- **Deployment**: GitHub Pages

## Development

```bash
cd astro-src
npm install
npm run dev
```

## Build

```bash
./build.sh
```
